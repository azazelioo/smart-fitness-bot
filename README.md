# Smart Fitness Assistant

Telegram-бот для персональных фитнес-тренировок с AI-анализом питания и оценкой травм.

## Описание

Smart Fitness Assistant - интеллектуальный Telegram-бот, который помогает пользователям в достижении фитнес-целей через персонализированные тренировки, анализ питания и профессиональную оценку травм. Бот использует современные технологии машинного обучения для распознавания продуктов питания и предоставления персонализированных рекомендаций.

## Возможности

### Профиль пользователя
- Расчет базального метаболизма (BMR)
- Вычисление общего расхода энергии (TDEE)
- Определение целевого калоража на основе целей пользователя
- Персонализированное распределение макронутриентов

### Тренировочные программы
- База из 50+ упражнений с детальными описаниями
- Генерация персональных программ тренировок
- Адаптация под уровень физической активности
- Рекомендации по интенсивности и частоте

### Анализ питания
- Распознавание продуктов питания по фотографии
- Использование модели MobileNetV2, обученной на датасете Food-101
- INT8 квантизация для оптимизации скорости
- Расчет калорийности и макронутриентов

### AI-оценка травм
- Интеллектуальный анализ травм с использованием Groq API
- Рекомендации по восстановлению
- Ежедневные советы по реабилитации

### Статистика и прогресс
- Отслеживание прогресса пользователя
- Визуализация достижений
- История тренировок и питания

## Технический стек

### Backend
- **Python 3.9+**
- **aiogram 3.4+** - асинхронный фреймворк для Telegram Bot API
- SQL**Alchemy 2.0+** - ORM для работы с базой данных
- **PostgreSQL / SQLite** - база данных

### Machine Learning
- **PyTorch 2.6.0** - фреймворк для нейронных сетей
- **MobileNetV2** - модель для классификации изображений
- **Groq API** - Large Language Model для AI-рекомендаций

### Дополнительные технологии
- **Docker / Docker Compose** - контейнеризация
- **aiosqlite / asyncpg** - асинхронные драйверы БД
- **python-dotenv** - управление переменными окружения

## Быстрый старт

### Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/azazelioo/smart-fitness-bot.git
cd smart-fitness-bot
```

2. Создайте файл `.env` на основе примера:
```bash
cp .env.example .env
```

3. Отредактируйте `.env` и добавьте необходимые токены:
   - `BOT_TOKEN` - токен Telegram бота от [@BotFather](https://t.me/BotFather)
   - `GROQ_API_KEY` - API ключ Groq (бесплатно, 7000 запросов/день)
   - `DATABASE_URL` - URL подключения к базе данных

### Запуск с Docker

```bash
docker-compose up -d
```

### Запуск локально

1. Создайте виртуальное окружение:
```bash
python -m venv venv

# Windows:
venv\Scripts\activate

# Linux/Mac:
source venv/bin/activate
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Запустите бота:
```bash
python -m bot.main
```

## Конфигурация

### Переменные окружения

| Переменная | Описание | Обязательна |
|------------|----------|-------------|
| `BOT_TOKEN` | Токен бота от BotFather | Да |
| `GROQ_API_KEY` | API ключ Groq для AI-рекомендаций | Да |
| `DATABASE_URL` | URL подключения к базе данных | Нет* |
| `OPENAI_API_KEY` | Альтернативный AI провайдер | Нет |
| `GEMINI_API_KEY` | Альтернативный AI провайдер | Нет |

*По умолчанию используется SQLite (`sqlite+aiosqlite:///./fitness_bot.db`)

### Примеры DATABASE_URL

SQLite (локальная разработка):
```
sqlite+aiosqlite:///./fitness_bot.db
```

PostgreSQL (производство):
```
postgresql+asyncpg://user:password@host:5432/database
```

## Модель распознавания продуктов

### Обучение

Модель MobileNetV2 обучена на датасете Food-101, содержащем 101 категорию блюд.

Для обучения собственной модели:

1. Используйте Jupyter Notebook `modules/food_analyzer/train_food_classifier.ipynb` в Google Colab
2. После обучения скачайте файл `food_model_best.pth`
3. Поместите модель в директорию `modules/food_analyzer/`

### Оптимизации

- **INT8 квантизация** - уменьшение размера модели и ускорение инференса
- **Уменьшенный размер входа** - 160px вместо 224px для быстрой обработки
- **torch.inference_mode()** - оптимизированный режим вывода
