# Smart Fitness Assistant

Telegram-бот для фитнеса с AI-анализом питания и генерацией персональных тренировок.

## Описание

Smart Fitness Assistant - интеллектуальный Telegram-бот, помогающий достигать фитнес-целей через персонализированные тренировки, анализ питания по фотографиям и расчет калорий. Использует Groq API (Llama Vision) для распознавания продуктов.

## Возможности

### Профиль пользователя
- Расчет базального метаболизма (BMR) по формуле Миффлина-Сан Жеора
- Вычисление общего расхода энергии (TDEE) с учетом уровня активности
- Определение целевого калоража на основе целей (похудение/набор/поддержание)
- Персонализированное распределение макронутриентов (белки/жиры/углеводы)

### Анализ питания
- Распознавание продуктов питания по фотографии через Groq API
- Автоматический расчет калорийности и КБЖУ
- История питания с отслеживанием калорий
- Рекомендации по питанию на основе целей

### Тренировочные программы
- База из 50+ упражнений с детальными описаниями
- Генерация персональных программ тренировок
- Адаптация под уровень физической активности и цели
- Рекомендации по интенсивности и частоте

### КБЖУ калькулятор
- Быстрый расчет калорий и макронутриентов
- Учет уровня активности
- Персонализированные рекомендации

## Технический стек

- **Groq API (Llama Vision)** - распознавание продуктов питания по фото

## Быстрый старт

### Установка

1. К лонируйте репозиторий:
```bash
git clone https://github.com/azazelioo/smart-fitness-bot.git
cd smart-fitness-bot
```

2. Создайте файл `.env` на основе примера:
```bash
cp .env.example .env
```

3. Отредактируйте `.env` и добавьте токены:
```env
BOT_TOKEN=your_telegram_bot_token
GROQ_API_KEY=your_groq_api_key
DATABASE_URL=postgresql+asyncpg://user:password@localhost:5432/dbname
```

### Запуск с Docker

```bash
docker-compose up -d
```

### Запуск локально

1. Создайте виртуальное окружение:
```bash
python -m venv venv

# Windows:
venv\Scripts\activate

# Linux/Mac:
source venv/bin/activate
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Запустите бота:
```bash
python -m bot.main
```

## Конфигурация

### Переменные окружения

| Переменная | Описание | Обязательна |
|------------|----------|-------------|
| `BOT_TOKEN` | Токен бота от BotFather | Да |
| `GROQ_API_KEY` | API ключ Groq для распознавания еды | Да |
| `DATABASE_URL` | URL подключения к базе данных | Нет* |
| `HTTP_PROXY` | Прокси для обхода блокировок | Нет |
| `HTTPS_PROXY` | HTTPS прокси | Нет |

*По умолчанию используется SQLite (`sqlite+aiosqlite:///./fitness_bot.db`)

### Получение API ключей

**Telegram Bot:**
1. Найдите [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте `/newbot` и следуйте инструкциям
3. Скопируйте полученный токен

**Groq API:**
1. Зарегистрируйтесь на [console.groq.com](https://console.groq.com)
2. Создайте новый API ключ в разделе Keys
3. Бесплатно: 7000 запросов/день, без кредитной карты

### Примеры DATABASE_URL

SQLite (локальная разработка):
```
sqlite+aiosqlite:///./fitness_bot.db
```

PostgreSQL (production):
```
postgresql+asyncpg://user:password@localhost:5432/fitness_bot
```

## Архитектура

### База данных

Проект использует SQLAlchemy ORM с асинхронными драйверами.

**Основные модели:**
- `User` - профиль пользователя с антропометрическими данными
- `FoodLog` - журнал питания с калориями и макросами
- `WeightLog` - история изменения веса
- `Training` - тренировочные программы
- `Exercise` - упражнения с описаниями

**Особенности:**
- Асинхронные запросы через asyncpg/aiosqlite
- Нормализованная структура с правильными связями
- Каскадное удаление зависимых данных
- Индексы для оптимизации запросов

### AI компоненты

**Groq API (Llama Vision)**
- Распознавание продуктов питания по фотографии
- Оценка калорийности и макронутриентов
- Бесплатный тариф: 7000 запросов/день
- Высокая скорость обработки (~1-2 секунды)

### Обработка запросов

1. Пользователь отправляет фото еды
2. Фото кодируется в base64
3. Отправляется запрос к Groq API с промптом
4. API возвращает название продукта
5. Поиск калорийности в локальной БД
6. Сохранение в журнал питания
7. Отправка результата пользователю

## Формулы расчетов

### Базальный метаболизм (BMR)

**Формула Миффлина-Сан Жеора:**

Для мужчин:
```
BMR = 10 × вес(кг) + 6.25 × рост(см) - 5 × возраст + 5
```

Для женщин:
```
BMR = 10 × вес(кг) + 6.25 × рост(см) - 5 × возраст - 161
```

### Общий расход энергии (TDEE)

```
TDEE = BMR × коэффициент активности
```

**Коэффициенты активности:**
- Минимальная (сидячий образ жизни): 1.2
- Низкая (1-3 тренировки/неделю): 1.375
- Средняя (3-5 тренировок/неделю): 1.55
- Высокая (6-7 тренировок/неделю): 1.725
- Экстремальная (2 раза в день): 1.9

### Целевой калораж

```
Похудение: TDEE - 500 ккал
Поддержание: TDEE
Набор массы: TDEE + 300 ккал
```
